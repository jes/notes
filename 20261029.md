## Solidcraft

OK wow, Solidcraft has an integration with codex and you can ask codex to make modifications to your model. Let's
give that a go.

I asked it what we were working on and it was really confused because it thought it needed to look at
the filesystem or find a git repo or something. I then clarified that we're working in Solidcraft and then it
used the Solidcraft tools to take a screenshot and correctly described the spacer I'm working on.

I then asked it to knurl the outside of the spacer and it worked for a really long time making dozens of
tool calls and then the Solidcraft UI locked up.

OK, locking up the UI is apparently down to boolean operations being extremely slow in Solidcraft and
also blocking the main thread while they do it. I think it is actually working.

It's tempting to profile this and see if I can improve it but Solidcraft is developing so quickly
that it may not be worth it. May be worth it for fun regardless, probably give it a go.

Although https://github.com/tangency-labs/solidcraft/issues/1597 this issue says the kernel is being replaced so
speed-ups are not wanted anyway, meh, forget it.
