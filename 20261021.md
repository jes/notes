## FluidNC on Arduino Nano ESP32

The plan is to flash FluidNC on to an Arduino Nano ESP32 and then connect to it over WiFi and "pretend" to run a job,
and do this near the plasma cutter, and see if it is still happy after repeatedly lighting the arc.

So how does one get FluidNC on to an Arduino Nano ESP32?

There is a web-based installer https://installer.fluidnc.com/ but Firefox is not supported.

Easier to use the CLI method or Chromium?

Download the `...-posix.zip` file from https://github.com/bdring/FluidNC/releases/latest

Put the ESP32 into bootloader mode by shorting B1 to GND and then pressing the rest button and then removing the short.

Then use `install-wifi_s3.sh` from the zip file to install FluidNC.

Then use `install-fs_s3.sh` to install the web interface.

And now I can connect to the WiFi using my phone but I thought it was meant to captive-portal-redirect me to
the WebUI, but it just acts like there's no internet.

`http://192.168.0.1/` is the web interface.

It says "File index.html.gz is missing, please upload it". I thought `install-fs_s3.sh` was meant to do this. I guess try that one again.

Tried again and still no good.

Codex noted that the script writes to 0x3d0000 but the partition table puts the flash at 0x610000, it fixed it for me and now is good.

Let's try and contribute that upstream shall we...

I can't find an existing issue or pull request that appears to relate to this.

Created https://github.com/bdring/FluidNC/pull/1928

Now, onwards, I need to upload a gcode file and set it running and then go and mess about with the plasma cutter.

Do I need an SD card in order to upload a gcode file?

No, you can go to the "FluidNC" tab, then the green folder icon, and upload a file there.

OK, I've uploaded a `demo.nc` to the internal filesystem, now how do I run it?

Apparently need to type `$LocalFS/Run=/demo.nc` into the console. Unclear why it is not `$Run=LocalFS/demo.nc`.

Sweet, looks to be working! To the garage...

I plugged the Arduino Nano ESP32 into the laptop USB port just for power, and the ESP32 reset as soon as I lit the arc.

...It works!

I kept lighting the arc over and over again, probably more than 100 times, and the demo program ran all the way to the end.
