OK well I started by measuring the work return current using the P80 torch, which I hadn't yet done.

With cutting current set to 30A I found that the work return current fluctuated wildly, multimeter reading occasionally 
reaching about 180mV but sometimes dropping as low as 50mV!

I previously measured the resistance on the work return cable as 0.006 Ohms, so 180mV corresponds to 30A, which is what we'd
expect continuously, and 50mV is only a bit over 8A! Which implies there are periods where a majority of current is flowing
through the pilot arc return instead of the work return!

As an experiment I turned the cutting current down to 20A, and in this case the current fluctuated a bit initially, but could
just be multimeter settling down (??) and then stabilised around 120mV, which is correct for 20A.

I previously only measured it at 20A on the Parkside torch so it is possible the same problem exists there, but I am not really
interested in the Parkside torch because it demonstrably performs worse.

So it looks like maybe at 20A the arc does (eventually?) reliably attach to the workpiece, but at 30A it spends a lot of the time
with a lot of the current attached to the nozzle instead of the work.

Even though the work-return current was generally higher on the 20A setting than the 30A setting, the cut is much weaker, doesn't
go all the way through. I guess the
fact that a lot of the current is going into the nozzle doesn't mean that the plasma jet itself is weaker. It is still a "30A plasma
jet", it's just 30A into the nozzle instead of into the work.

So in summary, this lends credence to the idea that we should be ensuring the pilot arc is disconnected shortly after starting.

However! I tried swapping M64 and M65 to see what would happen, and the arc started anyway, and the

So a few hypotheses here:

 * the pilot arc is arcing through the relay and the relay does nothing
 * I got the M64 and M65 the wrong way around, and somehow trying to light the arc with pilot arc disconnected makes the microcontroller reset
